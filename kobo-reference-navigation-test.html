Kobo Instapaper Reference Navigation Test

This page tests five ways to reach a reference without losing its citation text. Save the cache-busted test URL as a completely new Instapaper item, sync it to Kobo, and try each labeled case.

For A, B, C, and E, report one of: jump, popup, browser prompt, or nothing. For D, report expanded, always visible, removed, or nothing. If a case jumps, also try its return link.
